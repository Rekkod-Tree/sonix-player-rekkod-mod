# Sonix upstream: comparison with rekkod-mod

Snapshot: upstream `Jepl4r/sonix-player` at `a488e2587aab128d05c5b21dd16dd0604e4098ac` (original 1.3.0), our stable source at `00888a2`. Common ancestor: `dd59cfc`. There are 42 upstream commits outside our ancestry, touching 197 files; that does not mean 42 wholly missing features. The comparison below includes actual fork equivalents and later upstream reversions. No upstream code is imported by this review.

## Changes to defer or merge carefully

- [R1 pop fixes](https://github.com/Jepl4r/sonix-player/commit/84b939ee2b63ae8fde2354ebacca7004a4d77fd9) replace the codec/I2S module pair. The upstream commit carries binaries; inspect source/provenance/vermagic and validate pause/play/seek/track/standby on R1 before adopting the pair. The kernel image tree itself matches ours. Do not bring back the earlier software ramp and DAC mute that upstream reverted.
- [Stuck battery 0% recovery](https://github.com/Jepl4r/sonix-player/commit/1129f05d813c24437fcdc6c957f16b84642274b2) changes the gauge module; useful but not proof of battery calibration. [Low-battery shutdown](https://github.com/Jepl4r/sonix-player/commit/033fda59b0a92ccd60c0586f958fb46f293fbebe) needs an unknown-voltage guard and our safe-card shutdown path.
- [Charging while off](https://github.com/Jepl4r/sonix-player/commit/3ee9e03f5c8269228aba65618247dfe5575477d1) changes PMIC/reboot/startup behavior and draws a separate MiSans framebuffer UI. It needs dedicated power/FAT/ADB validation and visual adaptation.
- [Dynamic boot logos](https://github.com/Jepl4r/sonix-player/commit/adbb9477c843d9a2bc01ff96f62384c02895bf51) automatically erase/write an internal MTD block on theme/accent changes. Keep our agreed Rekkod branding and gray accent; do not introduce that flash-write policy into this optimization experiment.
- Merge translations by key. We already have 11 languages and 9 keyboard layouts; Czech is new. Whole-file replacement would lose 489 fork keys, including Graphite/services/recovery strings. Preserve our additional keys in both overlays.
- Preserve fork OTA identity, streaming clients, pinned font/audio dependencies and safe storage/recovery code. Upstream's version number is not a substitute for source comparison. Existing `CHANGELOG-rekkod.md` introductory numbers describe an older snapshot.

## Proposed order

First: the narrow seek/eventfd corrections and selected metadata compatibility, with focused tests. Next: PEQ entry, persistent queue history and lyrics, each adapted to existing components. Treat drivers, charge-only UI and boot-logo flash writes separately.

LTO was evaluated against unchanged alpha13 functionality in an isolated worktree, with default builds unchanged. See [the measured R1 experiment](LTO_EXPERIMENT_2026-10-17.md): 5.23% less CPU time in a synthetic offscreen renderer, a 1.13% larger player file, passing ABI/numeric/final-frame checks. It remains opt-in; complete-player runtime and battery benefits are not established. No upstream imports were mixed into that A/B test.
