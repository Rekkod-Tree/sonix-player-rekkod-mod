# Пресеты и проверка звука

Пресеты лежат отдельно от прошивки: `presets/peq/soundcore-space-one-pro/`.
Скопируйте нужные `.txt` в каталог `PEQ` на карте, затем выберите
**Настройки → Музыка → PEQ → шестерёнка → Загрузить пресет**.
Копирование файла само по себе ничего не включает. Сначала безопасно отключите
карту от ПК, если использовался режим USB-накопителя.

## Варианты

| Файл без расширения | Изменение | Результат прослушивания |
| --- | --- | --- |
| Space One Pro - Voice test | 2200 Гц +1,5 дБ; 250 Гц +0,8 дБ | Голос понравился, хотелось больше плотности |
| Space One Pro - Body test | Как Voice, но 250 Гц +1,2 дБ | Понравились плотность и воспринимаемое разделение |
| **Space One Pro - Body Voice test** | Body плюс 3500 Гц +0,7 дБ | **Предпочтительный вариант: голос свободнее, плотность сохранена** |
| Space One Pro - Natural test | Voice плюс верхняя полка 8000 Гц −1,5 дБ | Архивный вариант для сравнения |
| Space One Pro - Body Voice Natural test | Body Voice плюс верхняя полка 8000 Гц −1 дБ | Отвергнут: ощущение пелены, меньше присутствия |

У всех вариантов предусиление −2 дБ. Точные типы фильтров и Q находятся в файлах.
Оценки субъективные, зафиксированы 18.10.2026; это не измеренная коррекция AutoEq.

## Условия подбора

Подбирались для **soundcore Space One Pro**, HearID выключен, адаптивное ANC,
передача с HiBy R1 по LDAC. EQ самих наушников достоверно не проверен.
Это добавка к существующему MSEB, а не самостоятельная универсальная настройка:

```text
MSEB: enabled=1, range=100
v0..v9: -23, 8, 1, 0, 17, 0, 22, 19, 0, 29
Stereo width: 100% (при включённой обработке); crossfeed выключен.
```

Файлы PEQ не меняют MSEB, ANC, громкость и ширину сцены. Указанные значения
служат контекстом эксперимента, автоматически их применять не нужно.
После успешного Body Voice дальнейшее сравнение остановлено из-за усталости
от переключений; окончательная оценка естественности остаётся за слушателем.

## Хелперы и границы проверки

`tools/audio-audit/run.sh` запускает на Linux/WSL численные пробы **текущего**
`sonix-player/src/system/audio/eq.c`: импорт APO, значения фильтров, частотный
отклик, пример перекрытия полос и влияние расширения стереобазы на тестовый сигнал.

```sh
bash tools/audio-audit/run.sh > /tmp/sonix-audio-audit.log
```

Пробы не включают звук и не обращаются к плееру. Расчёт отклика не измеряет
акустический результат наушников и не доказывает отсутствие клиппинга всей
цепочки MSEB/PEQ на произвольной записи. Исходные пресеты сохраняйте: новые
варианты добавляйте отдельными файлами с описанием изменения и результата.
Личные конфиги, токены, сырые логи и снимки устройства в Git не добавляйте.
