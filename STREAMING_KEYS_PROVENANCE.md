# Происхождение ключей сервисов Sonix

Проверено 18 октября 2026 года по исходникам оригинального Sonix 1.3.0.
Секретные значения не извлекались и здесь не приводятся.

- **Tidal и Qobuz:** автор прямо указывает в `streamkeys.h`, что ключи
  приложения принадлежат HiBy и находятся в штатном `hiby_player`.
  Это подтверждённое описание повторного использования ключей HiBy,
  а не предположение по похожему протоколу.
- **Podcast Index:** комментарий описывает собственную пару ключей приложения,
  запрашиваемую на podcastindex.org; она не относится к приложению HiBy.
- **Last.fm:** предусмотрена собственная регистрация API-приложения через
  last.fm/api. Это не свидетельство наличия действующих ключей в каждом образе.

Ключи приложения отделены от пользовательского входа и прав подписки.
README требует предоставить ключи при сборке; секретные файлы исключены из Git.
В образ они могут включаться в запечатанном `streaming-keys.bin`, связанном
с конкретной программой. Наличие этого файла само по себе не подтверждает
наличие ключей всех сервисов или их работоспособность.
