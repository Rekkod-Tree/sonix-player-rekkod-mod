# Штатные параметры Tidal и Qobuz

Для alpha21 подготовлены параметры приложений из сохранённого штатного образа
HiBy R1. Они подключаются через существующий механизм Sonix: закрытый
`streaming-keys.ini` упаковывается в `streaming-keys.bin`, а ключ его открытия
передаётся при сборке. Значения, исходный образ и личные сессии в Git не входят.
Параметры Яндекс Музыки при добавлении не менялись; исходный файл сохранён
и проверен перед записью.

Это параметры клиента, а не учётная запись слушателя. Для прослушивания нужен
обычный вход в сервис и подходящая подписка. Личный вход и воспроизведение
Tidal/Qobuz на R1 пока не приняты.

## Что проверено 19 октября 2026 года

- Tidal: прослежены штатное формирование `client_id` и передача
  `client_secret`. Сервис выдал данные авторизации устройства, затем принял
  пару клиента при опросе токена: HTTP 400 `authorization_pending`.
  Пользователь вход не подтверждал, токен аккаунта не получен.
- Qobuz: идентификатор используется в штатных запросах каталога; секрет
  добавляется к строке `trackgetFileUrlformat_id…` перед вычислением MD5.
  Публичный каталог с этим идентификатором вернул HTTP 200 и один альбом.
  Подписанная выдача аудио без личного входа не проверялась.
- У штатного образа проверены цепочка частей rootfs и полный MD5; у
  извлечённой программы сохранён SHA-256. Подробности и ответы с временными
  кодами входа хранятся приватно вне исходного репозитория.

Эти результаты подтверждают возможность использования штатных параметров
в нашей сборке. Они не устанавливают, откуда автор Sonix получал значения
для своих опубликованных образов. README автора описывает загрузку ключей,
но не доказывает их происхождение.

## Дополнительные параметры владельца сборки

В локальный закрытый файл добавлены пары `api_key` / `api_secret` для
Podcast Index и Last.fm. Проверка настоящим C-загрузчиком подтверждает,
что зашифрованный ресурс содержит все пять наборов параметров сервисов.

Podcast Index принял подписанный запрос поиска: HTTP 200, одна запись
каталога. Это проверка API; воспроизведение и скачивание выпуска на R1
не подтверждены этим запросом.

Last.fm на запрос получения неподтверждённого токена вернул HTTP 403 и
XML-ошибку 11 `Access Denied`. Проверка через GET и POST дала одинаковый
отказ. Ключ нельзя считать ни проверенным, ни заведомо неверным; личный
вход и скробблинг не выполнялись. Ответ сохранён приватно для диагностики.
