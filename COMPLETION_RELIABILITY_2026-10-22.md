# Надёжная доставка фоновых результатов

Этот коммит исправляет №54 и №56–58 отдельного реестра Sonix/R1.
Это проверка исходников и диагностического кандидата, ещё не выпуск alpha26.

## Поведение

- Gearboy сохраняет завершение поиска до получения интерфейсом. Заполненная
  очередь уведомлений больше не теряет результат и не оставляет поиск занятым.
  Нехватка памяти при сканировании возвращает ошибку вместо частичного списка.
- Загрузчик обложек книг удерживает один результат до подтверждения GUI.
  Уход со страницы, повторный вход и остановка освобождают результат один раз.
- AutoEQ сохраняет результат операции и владеет своим уведомлением. Позднее
  завершение не закрывает новое уведомление и не открывает устаревший поиск.
- Существующий GUI-цикл обслуживает три сохранённых результата перед LVGL,
  включая выключенный экран. Новые потоки, очереди и таймеры не добавлены.
- Очередь согласует нижнюю границу прокрутки после уменьшения подписи или
  перехода в пустое состояние, сохраняя допустимую позицию и защиту жестов.

## Проверка

Исходник диагностического кандидата:
`41b344f3d38f220fc73b66cd7670f575587b3053be9d32462cc1b3a697f7a7e1`.
Player:
`e34f6ebb36041c337f7b5ee1892f932983bc8b269e095f6caf3c85e5305e48d4`.

Независимые ревью приняты. Фактический код модулей прошёл ASan/UBSan с
переполненными очередями, ошибками выделения памяти, закрытием, повторным
входом и отрицательными контролями. Проверка геометрии использует настоящий
LVGL на обеих панелях и в обеих темах. Host-сценарии оформления, главной и
воспроизведения прошли на 480×800 и 480×720 без новых предупреждений.
Target собран с LTO/O3, без PGO/fast-math; ABI glibc 2.22 проверен, не пропущен.

На R1 проверены завершение пустого GB/GBC-поиска, переключение вида, возврат,
пустая страница книг и настоящий AutoEQ-поиск с загрузкой индекса. Пресет не
применялся. Установленная alpha25, настройки и три базы восстановлены;
boot ID не изменился. Временные файлы запуска удалены. Нормальный индекс
AutoEQ размером 851757 байт оставлен для последующего использования.

Дополнительно подтверждена ранее включённая правка скрытого курсора №39:
видимое поле даёт анимацию 900 мс, а семь полных интервалов на экране импорта
после закрытия поля не содержат её. Батарейная автономность не измерялась.

## Воспроизведение проверок и границы

Из `sonix-player/`:

```sh
python3 tests/gearboy_completion_test.py --sanitize
python3 tests/ebookcovers_completion_test.py --sanitize --negative
python3 tests/autoeq_completion_test.py --sanitize --negative
python3 tests/gui_completion_loop_test.py --sanitize
```

Нужны компилятор C и проектные LVGL-заголовки; параметры путей описаны в
`--help` каждого набора. Исполнение использует временные тестовые каталоги.

На R1 не инъецировались OOM/переполнение очередей/повреждения карты. Непустая
доставка обложек проверена фактическим кодом на host, без EPUB-образца на R1.
Поздние Radio/AirPlay-названия очереди проверены через actual-LVGL fixture,
а не настоящий транспорт. Эти исправления не закрывают отдельное владение
картой для GBDB/AutoEQ, проблему редкого перезапуска или внешние BT/RM01/ЦАП.

Workspace evidence: `output/alpha26-final-20261022/native-completion-wave.json`,
`native-caret39.json`, `host-completions/manifest.json`,
`target-completions-off/manifest.json` и отчёты независимых ревью.
