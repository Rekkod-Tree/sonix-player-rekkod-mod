Подключение сервисов

Яндекс Музыка · Звук · Subsonic+
01Яндекс МузыкаВход с телефона по коду или QR+
  1. Подключите R1 к Wi-Fi. Откройте «Стриминг → + → Яндекс Музыка».
  2. Откройте сервис. Отсканируйте QR или перейдите по адресу, показанному на плеере.
  3. Войдите в свой аккаунт Яндекса и подтвердите код. Пароль на плеере вводить не нужно.

Качество выбирается на странице сервиса. Сохранение — из меню трека, альбома или полного плеера. Для книги откройте раздел аудиокниг и скачивание целиком.

Высокое качество не означает, что любой трек придёт в FLAC: вариант определяет сервис и аккаунт.

02ЗвукИмпорт токена вашего аккаунта с карты+
  1. На компьютере войдите в свой аккаунт на zvuk.com.
  2. В том же браузере откройте zvuk.com/api/tiny/profile. Найдите поле token и скопируйте только его значение. Если открылась проверка браузера, сначала завершите её на сайте.
  3. Создайте в корне microSD файл zvuk_token.txt в UTF-8. Вставьте токен одной строкой: без кавычек и без token=. Проверьте, что Windows не добавила второе расширение .txt.
  4. Безопасно извлеките USB-накопитель, верните карту плееру, включите Wi-Fi. Добавьте Звук через «Стриминг → +» и откройте его страницу.

После успешного входа файл удаляется, сессия хранится во внутренней памяти. Окончание .bad означает отклонённые или некорректные данные. При временной сетевой ошибке файл остаётся для повторной попытки.

Не отправляйте токен в комментарии или поддержку. Наличие файла само по себе не подтверждает успешный вход. Способ импорта может зависеть от изменений API сервиса.

03Subsonic / NavidromeВаша домашняя музыкальная библиотека+
  1. Добавьте Subsonic через «Стриминг → +».
  2. Укажите адрес своего сервера, логин и пароль.
  3. Либо создайте в корне карты subsonic.txt: адрес, логин и пароль на трёх отдельных строках, в этом порядке.
Пример с вымышленными данными
https://music.example.org
my_login
my_password

После успешного импорта файл удаляется; .bad означает отклонённые данные. Без сети файл остаётся. В обычном token-режиме хранится токен с солью; старый парольный режим зависит от сервера. Доступ к домашнему серверу вне дома настраивается отдельно.

Установка и обновление

Образы и recovery+
  1. 01

    Выберите свой образ

    Для HiBy R1 — r1.upt. Совместимость аппаратного варианта смотрите в описании сборки. Проверки мода сосредоточены на R1.

  2. 02

    Подготовьте карту

    Сохраните важные данные. Положите файл в корень microSD и безопасно извлеките накопитель на компьютере.

  3. 03

    Обновите с карты

    На плеере: «Настройки → Система → Обновление → С карты SD». Обеспечьте достаточный заряд и не прерывайте питание.

Нужно ли менять recovery?

Нет, это добровольно. Обычное совместимое обновление не требует заранее исправленного recovery и не переписывает его автоматически.

Мастер исправляет известное поведение поддерживаемого старого recovery R1: чтение карты переводится в режим только для чтения. Это устраняет конкретный механизм некорректного отключения, а не ремонтирует уже повреждённую FAT.

Старый recovery не означает привязки к моду. Формат и проверки совместимых .upt не меняются; неизвестные образы мастер не исправляет. Перед отдельной правкой нужны резервные копии, внешнее питание, заряд от 50% и место на карте.

Технические сведения

Оптимизация, проверки и ограничения+

Оптимизация

  • LTO и O3. Совместная оптимизация программы; O3 для горячих участков, O2 для остальных до финального LTO. Без fast-math.
  • PGO с реального R1. Профиль обычного использования, без обучающих счётчиков в конечной программе. Новый код требует свежего обучения.
  • Меньше фоновой работы. Ленивые страницы, ограниченные кеши, обновления только изменившихся данных, меньше записи во время настройки.
  • Проверяемое сохранение. Карта, загрузки, плейлисты и конфигурация учитывают ошибки и смену носителя.
Техническая база, ограничения и материалы для разработчиков

Совместимость важнее новой цифры

База R1 BCM — HiBy OS 2.0 с согласованным ядром и модулями. Обновлены SQLite, приватный OpenSSL, ALSA и BlueALSA; ABI устройства и необходимые старые библиотеки сохраняются.

Новый PCM-драйвер с затуханием из Sonix не перенесён из-за обращения с DoP. Исправление щелчков этого драйвера здесь не заявляется.

Чего пока не обещаем

Spotify не включён в образ из-за лимита раздела. MQA не добавлен. Прогресс книг не синхронизируется с аккаунтом сервиса; текстовые книги Яндекс Книг — отдельная задача. На книгу при скачивании — до 300 глав; весь архив подкаста одним действием не скачивается.

Причина редкого перезапуска и все варианты заиканий Bluetooth не объявлены устранёнными. Испытания длительной автономности и аналогового качества не заменяются короткими программными тестами.
